**优先级约定**

- **P0**：首批游戏内容必须覆盖（高频考点、执业医师/阶段考试底座、跨专业共通）
- **P1**：第二批扩展（临床专科、经典深化、整合病种）
- **P2**：可选/特色（气功、实验针灸、热带医学、长学制科研方法等）

**建议游戏类型缩写**

- 翻卡片 = 记忆翻翻乐（正反面配对）
- 闪卡 = Anki 式正背/反背
- 选择题 = 单选/多选/病例题
- 拖拽匹配 = 术语↔定义、穴名↔定位、药↔证、证↔方 等

## 1. 典型学年节奏（综合，非某校强制课表）

### 1.1 中医学 / 针灸推拿学（五年制，典型）

| 学年 | 侧重 | 代表内容（综合 S1–S6） |
|------|------|------------------------|
| Y1 | 通识 + 中医入门 + 西医形态入门 | 思政/英语/体育；中医基础理论、医古文；系统解剖（针推常含穴位局解） |
| Y2 | 中医诊断·方药 + 西医生理病理起步 | 中诊、中药、方剂；生理、生化；开始经络腧穴（针推） |
| Y3 | 经典 + 西医病理药理 + 针灸推拿主干 | 内经/伤寒/金匮/温病；病理、药理；刺法灸法、推拿手法；诊断学基础起步 |
| Y4 | 中西医临床课 + 见习/中期实习 | 中医内/外/妇/儿/骨伤；针灸治疗、推拿治疗；西医内/外；见习或中期实习 |
| Y5 | 毕业实习（约 48–52 周） | 中医临床科室轮转 + 部分西医/急诊；OSCE/经典等级等毕业考核 |

### 1.2 临床医学五年制（典型，S7–S9）

| 学年 | 侧重 | 代表内容 |
|------|------|----------|
| Y1 | 通识 + 数理化 + 细胞/解剖入门 | 思政人文；化学物理数学英语；细胞生物、系统解剖起步 |
| Y2–Y3 | 生物医学核心 | 组胚、生理、生化分子、微免、病理、病理生理、药理、寄虫等 |
| Y3–Y4 | 诊断与临床理论 + 见习 | 诊断学、外科学基础、影像；内/外/妇/儿/传染 + 小科；技能训练 |
| Y5 | 毕业实习 ≥48 周 | 内/外/妇/儿等轮转；OSCE；西医院校常含「中医学」概论课（S7 要求） |

### 1.3 中西医结合临床医学（典型，S10）

并行或分模块开设：**中医基础+经典**、**西医基础+诊断**、**中西医结合内/外/妇/儿/伤**、针灸推拿；结合课程占比校际差异大（约 6%–18%）。实习常「中医科室 + 西医科室」双轨（如海南医科大示例：中医约 26 周 + 西医约 14 周 + 社区等）。

## 6. 设计备注（避免踩坑）

1. **不要假设全国统一学期课表**：以「模块 + 优先级」组织内容，再用标签过滤专业（中医/针推/临床/中西医）。  
2. **中医学标准 2025** 明确要求中医基础、经典、临床 + 必要西医基础与临床 + 预防（含中医养生）+ 科学方法 + 师承要素（S1）。  
3. **临床医学标准 2016** 明确生物医学核心清单、临床核心清单、毕业实习≥48 周，并要求安排中国传统医学相关课程（S7）。  
4. **中西医结合** 校际「结合课」学分占比差异大（S10 比较研究）；游戏侧宜做「对照卡」而非强行统一某一校比例。  
5. **针推** 相对中医学加厚：经络腧穴、刺灸、针灸治疗、推拿手法/治疗；北中医另有气功与实验针灸（S4）。  
6. 执业/阶段考试导向：P0 包优先对齐「三基」与高频辨证/穴/药/方/解剖生理病理药理诊断内科。
